# Reaction-Time
Files for, "Reaction Time to Different Stimuli Under Different Levels of Concentration."
Find attatched the resource pack used, and the mod used. Use the mod in conjunction with the resource pack.

Keybinds:
L = Change Stimuli Type,
V = Trigger Stimuli/Respond.
Press L to switch to the stimuli type you wish to test the reaction time for.
Press V to trigger the stimuli (do away from the person being tested).
Person being tested presses V on their keyboard to respond to the stimuli and get a time.
